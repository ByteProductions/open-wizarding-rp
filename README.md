# Open Wizarding RP

An original, modular roleplay framework planned for ArcaneMP, with configurable school progression and content adapters.

**Status: planning and repository bootstrap. No playable framework release exists yet.**

Start with the [roadmap](docs/ROADMAP.md), [contribution workflow](CONTRIBUTING.md) and [security policy](SECURITY.md).

Reuse compatible platform services and public mods; implement the missing school, career and world rules as independent resources. Third-party mods and Foundations retain their own licences and are not bundled here. The MIT licence covers this project's original contributions.

Development checks: `python scripts/check_repository.py`. Gameplay tests and language-specific CI will be added with implementation.

This is an independent fan project, not affiliated with Wizarding Academy, ArcaneMP, Warner Bros., Avalanche Software or other rights holders. Players must obtain their own legitimate game and dependencies.
